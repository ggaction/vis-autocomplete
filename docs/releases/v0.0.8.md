# v0.0.8

This release integrates the changes made after v0.0.7 on the shared main branch.

- Branch-preserving Graph View with thumbnail nodes, zoom/pan, a two-row default fit, fewer edge crossings, and continuous history hover previews. Linear View remains available.
- Detailed, consent-aware recommendation and editing research logs, including exposures, parameter exploration, searches, history navigation and structural code changes. Existing explicit consent is retained. Dataset rows, uploads and authentication details are excluded.
- Bounded asynchronous gzip delivery, offline queuing, withdrawal/deletion handling and a pseudonymous analysis exporter.
- Arrow-key movement of selected guides, font-family previews, and Shift+Enter support alongside Cmd+Enter for inline line breaks.
- Filtered mark domains now fit retained values. Recommendation score footers are hidden without changing ranking or research records.
- Presentation embedding is limited to hyeonword.com and the approved 127.0.0.1 development ports 5173/5174.
