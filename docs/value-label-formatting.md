# Value label formatting

Add value labels and Edit value labels expose a Number format group: Automatic, Decimal, Percent and Scientific. Manual formats have a 0–12 Decimal places slider. Categorical labels keep their original strings and hide numeric controls. The create card also retains font size and placement controls, within four visible groups.

Automatic formatting reads actual final marks, including aggregation, stacking and individual facet populations. It prefers two decimal places for fractional values and none for integers, increases precision when needed to distinguish values, and uses shorter fixed/scientific notation when labels would exceed roughly eight characters. Candidate formats keep relative rounding error within 0.5%; more space is allowed when necessary to distinguish values. Only differences at machine precision are treated as arithmetic noise. At the native 12-decimal limit, extremely close values can still round together. Raw data and numeric encodings are unchanged.

The app emits ordinary `createMarkLabels({format,layout,...})` and `encodeText({target,format,...})` calls. Editing retains label membership, manual text overrides, existing placement and collision policy. Automatic resolves to an explicit native format in saved code; later changes can select Automatic again to recalculate it.

New label collections use bounded local collision adjustment with leader lines for displaced labels. Maximum displacement decreases from 12 to 6 to 2 pixels for collections above 250 and 500 marks. Above 1,000 labels, automatic movement is disabled and numeric shortening still applies to every label. No values are silently removed. Native collision lookup indexes nearby rectangles, preserves ordered tie breaking and warning pairs, and retains the shared work guard for genuinely dense layouts.

Validation covers fixed/percent/scientific formats, zero/negative/tiny/large/close values, integer categories, aggregated bars, pie and line endpoint labels, points, faceted and adjacent charts, semantic text overrides, persistence, native collision-oracle equivalence and 5,000 separated labels. Browser coverage exercises both display modes, category switching, preview without commit, Apply, reformatting and Undo/Redo.
